University HR Management System
A database-driven web application developed as a university DB course project. The system manages university staff across multiple departments, handling employee records, leave requests, role assignments, and approvals through a role-based access control system.
Features

Employee management (full-time/part-time, active/resigned/on-leave)
Leave request system (annual, medical, accidental, unpaid, compensation)
Multi-level leave approval workflow
Role-based dashboards (President, VP, Dean, HR Manager, HR Rep, etc.)
Department and role organization
Holiday management
Document tracking

Tech Stack

Frontend: ASP.NET Web Forms (ASPX)
Backend: C# (.NET Framework 4.8)
Database: Microsoft SQL Server (LocalDB)
IDE: Visual Studio 2022

Setup

Run createAllTables.sql to create the database schema
Run team.sql to seed the data
Open MyDatabaseConnection.slnx in Visual Studio 2022
Press F5 to run

Default login: any employee email from the database with password Pass1234
